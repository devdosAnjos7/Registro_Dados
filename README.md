# Registro de Dados com Streamlit 🚀

Uma aplicação web simples feita em **Python** utilizando a biblioteca **Streamlit** para cadastrar informações e salvá-las em um arquivo de texto local.

## 🛠️ Tecnologias
- **Python**
- **Streamlit** (Interface Web)
- **Arquivo TXT** (Persistência de dados)

## ⚙️ Funcionalidades
- Interface amigável no navegador.
- Campos de formulário para entrada de dados.
- Botão para salvar as informações diretamente em um arquivo `.txt`.
